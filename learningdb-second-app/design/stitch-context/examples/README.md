# Example JSON fixtures

Illustrative payloads for Stitch / agents. **Replace** with real responses from your DB when demoing layout.

| File | Maps to |
| --- | --- |
| `health.response.json` | `GET /api/health` |
| `tables.response.json` | `GET /api/tables` |
| `table-columns.response.json` | `GET /api/tables/{name}/columns` |
| `table-rows.response.json` | `GET /api/tables/{name}/rows` |
| `tables-insert.request.json` | `POST /api/tables/insert` |
| `tables-patch.request.json` | `PATCH /api/tables/{name}/rows` |
